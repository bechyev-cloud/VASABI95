# VASABI — меню и калькулятор заказа (PWA)

Клиент открывает ссылку, выбирает бургеры, пиццу, суши и т.д., видит итоговую сумму,
копирует текст заказа и отправляет его в WhatsApp. Работает как приложение (можно установить
на главный экран) и открывается без интернета.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Само приложение |
| `menu.txt` | **Меню и цены для всех клиентов** — меняйте здесь |
| `manifest.json`, `sw.js` | Установка как приложение; после установки всё хранится на телефоне и работает без интернета |
| `icons/` | Иконки |
| `cars/` | Фото машин X-Car: `1.jpg`, `1-s.jpg` (миниатюра) … Количество — `CAR_PHOTOS` в `index.html` |

## Как выложить на GitHub (с телефона тоже можно)

1. Зайдите на github.com → **New repository** → имя, например `vasabi` → **Public** → Create.
2. **Add file → Upload files** → загрузите все файлы и папку `icons` (можно распаковать архив и перетащить всё сразу) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты появится ссылка вида `https://ВАШ-ЛОГИН.github.io/vasabi/` — её и отправляйте клиентам.

## Как поменять цены для всех клиентов

1. В приложении: ⚙️ **Настройки → Меню** — измените цены/позиции/категории.
2. **Копии → Экспорт → Скопировать**.
3. На GitHub откройте `menu.txt` → ✏️ (Edit) → удалите старый текст, вставьте новый → **Commit changes**.

Или правьте `menu.txt` прямо на GitHub. Формат простой:

```
@name = VASABI
@phone = 79280017548

[🍔 Бургеры]
Чизбургер = 230
Двойной чизбургер = 330
```

- `[эмодзи Название]` — категория
- `Название = цена` — позиция
- `@phone` — номер WhatsApp, куда клиенты отправляют заказ (в формате 7XXXXXXXXXX)

## Резервные копии

⚙️ **Настройки → Копии**:
- **Экспорт** — всё меню текстом: скопировать, отправить в WhatsApp, скачать .txt
- **Просмотр** — вставить присланный текст и посмотреть меню целиком (новые позиции и изменённые цены подсвечены) до импорта
- **Импорт** — заменить меню вставленным текстом (с подтверждением)

## Работа без интернета

После первого открытия сайта приложение сохраняется на телефоне целиком: страница, иконки, фото машин, шрифты.
Дальше оно открывается мгновенно и без интернета. Когда интернет есть, новая версия тихо скачивается в фоне
и включается при следующем запуске. Установить на рабочий стол можно только с сайта (GitHub Pages), не из файла.

## Обновление приложения

Если меняете `index.html`, увеличьте версию в первой строке `sw.js`
(`vasabi-v1.0.0` → `vasabi-v1.0.1`), чтобы у установленных приложений подтянулась новая версия.
